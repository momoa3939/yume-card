## ① GitHub Pagesへの公開方法（最初の1回だけ）

1. **GitHubのアカウントを作る**（すでに持っていればスキップ）
   → https://github.com/ にアクセスして「Sign up」

2. **新しいリポジトリを作る**
   - 右上の「＋」→「New repository」
   - Repository name：好きな名前でOK（例：`yumecard-kakeibo`）
   - 「Public」を選ぶ（GitHub Pagesの無料枠はPublicのみ）
   - 「Create repository」

3. **このZIPの中身をアップロードする**
   - 作ったリポジトリの画面で「Add file」→「Upload files」
   - ZIPを解凍してできた以下のファイル・フォルダを、**フォルダ構成を保ったまま**ドラッグ＆ドロップ
     ```
     index.html
     manifest.json
     service-worker.js
     icons/（フォルダごと）
     lib/（フォルダごと）
     ```
   - 下の方にある「Commit changes」を押して保存

4. **GitHub Pagesを有効にする**
   - リポジトリ画面の「Settings」タブ
   - 左メニューの「Pages」
   - 「Branch」を `main`（または `master`）、フォルダは `/ (root)` を選んで「Save」
   - 数分待つと、ページ上部に公開URLが表示される
     （例：`https://ユーザー名.github.io/yumecard-kakeibo/`）

5. **スマホでアクセスして「ホーム画面に追加」**
   - 表示されたURLをスマホのChromeで開く
   - 「ホーム画面に追加」または「アプリをインストール」を選ぶ

## ② 更新するときの手順（中身を直したくなったら）

1. リポジトリ画面で、更新したいファイル（例：`index.html`）を開く
2. 鉛筆マーク（Edit）をクリック
3. 中身を書き換えて「Commit changes」
4. **数分待てば、次にアプリを開いたときに自動で最新版になる**
   （index.htmlは「ネットワーク優先」設定にしてあるので、バージョン番号などを気にする必要はなし）

※ もし表示が切り替わらない場合は、下の④「表示をリセットする」ボタンを試してみて。

## ③ バックアップのおすすめタイミング

記録一覧タブに「📦 バックアップ保存」ボタンがあります。これが一番確実な方法：

- 押すと `.json` ファイルがダウンロードされる（記録データ・締め日修正の内容すべてを含む完全な形）
- 復元するときは「📦 復元」ボタンでこのファイルを選ぶと、
  - 作成日時・件数・記録期間が表示されて内容を確認できる
  - 「追加する」（今のデータに足す）か「全部置き換える」かを選べる
- 機種変更のときは、新しい端末で「全部置き換える」を選べば、まるごと引き継げる

「📥 Excelに書き出す」も引き続き使えるけど、これは主に**人が目で見て確認する用**（xlsxで開いて内容チェックしたいとき）。
**完全なバックアップ・復元にはJSON版（📦バックアップ保存/復元）を使うのがおすすめ**。

以下のタイミングで「📦 バックアップ保存」を押しておくと安心：

- **月末・締め日のあと**（1ヶ月分のキリがいいタイミング）
- **スマホを機種変更する前**（一番大事なタイミング）
- **アプリをしばらく触ってないな、と思ったとき**（月1回くらいのペースが目安）
- **「表示をリセットする」ボタンを使う前**（念のため）

書き出したExcelファイルは、Googleドライブや、いつものクレジットカード管理表と合体させて保管しておくと二重に安心。

## ④「表示をリセットする」ボタンを使う場面

グラフタブの一番下にあるボタン。こんな時に使う：

- 更新したはずなのに、**古い画面のまま**変わらない
- レイアウトが**崩れて見える**
- なんとなく**動きがおかしい**（ボタンが反応しない、グラフが出ないなど）

**安心して押してOKな理由**：このボタンは「表示用のキャッシュ」だけを消す仕組みで、
入力した記録データ（localStorage）には一切触れない設計にしてある。
押すと自動で再読み込みされて、直っているはず。

それでも直らない場合は、この会話（Claude）に「表示がおかしい」と伝えてもらえれば、
一緎に原因を確認できるよ。

## ⑤ データはどこに保存されている？

この家計簿のデータは、サーバーではなく**このブラウザ（この端末）のlocalStorage**に保存されています。

そのため：

- **別のスマホでは自動では引き継がれません**（同じ端末・同じブラウザでしか見れない）
- **Chromeのデータを完全に削除するとデータも消えます**（「サイトデータを削除」「閲覧履歴データを削除」など、Chromeの設定から丸ごと消す操作をすると、キャッシュだけでなくlocalStorageも一緒に消えてしまう）
- **機種変更前には必ず「📥 Excelに書き出す」でバックアップしてください**（新しいスマホでこのアプリを開いても、データは自動移行されない）

上の④「表示をリセットする」ボタンは、キャッシュだけを消してlocalStorageは消さない安全な仕組みだけど、
Chromeの設定から直接「データを削除」する操作は、これとは別物で**家計簿のデータごと消えてしまう**ので注意。
